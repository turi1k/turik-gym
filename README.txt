TURIK GYM — файлы для публикации

1. Загрузите ВСЕ файлы и папку icons в один GitHub-репозиторий.
2. В GitHub откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку / (root), затем Save.
5. После публикации откройте выданный HTTPS-адрес в Safari на iPhone.
6. Нажмите Поделиться → На экран «Домой» → Добавить.

Приложение сохраняет веса, отметки и историю локально в браузере этого iPhone.
Не очищайте данные Safari для этого сайта, иначе локальные записи могут пропасть.
Токены и пароли для работы приложения не нужны.
