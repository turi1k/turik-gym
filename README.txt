TURIK GYM — ОБНОВЛЕНИЕ С ПРОГРЕССИЕЙ И ТЕХНИКОЙ

1. Открой свой GitHub-репозиторий turik-gym.
2. Загрузи index.html и sw.js из этого архива в корень репозитория.
3. Подтверди замену старых файлов (Commit changes).
4. Подожди 1–3 минуты.
5. На iPhone полностью закрой Turik Gym и открой снова. Если старая версия осталась, открой сайт в Safari, обнови страницу и затем снова запусти приложение с экрана «Домой».

Важно:
- Не удаляй папку icons и manifest.webmanifest — они уже есть в твоём репозитории.
- Старые ключи localStorage не удаляются. Тренировки, заметки, питание, вес тела и история остаются на этом устройстве.
- После обновления сделай резервную копию во вкладке «Данные».
- Добавлена вкладка «Техника» с инструкциями по упражнениям всех трёх тренировочных дней.
- Прогрессия рассчитывает следующую цель по последней сохранённой тренировке каждого упражнения: сначала добавляет повторения, затем предлагает небольшой шаг веса.
- Количество упражнений и подходов не увеличивается автоматически: текущий объём уже достаточный, а механическое добавление объёма не ускоряет рост и может ухудшить восстановление.
- Аксессуары продолжают меняться по неделям. Основные упражнения остаются.
- Данные хранятся локально на этом устройстве и не синхронизируются автоматически между телефонами.
